Termos de Uso — P-JARI v{{ versao }}

1. Objeto

O P-JARI é uma ferramenta de assessoria para julgadores da JARI/SC. Todas as decisões finais permanecem sob responsabilidade exclusiva do julgador.

2. Responsabilidade

O sistema auxilia na elaboração de pareceres, mas não substitui a análise e o julgamento humano. O julgador é integralmente responsável pelo conteúdo do parecer final.

3. Dados e Privacidade

Os dados processuais são armazenados de forma segura e utilizados exclusivamente para a geração de pareceres. Não há compartilhamento com terceiros.

4. Uso de IA

O sistema utiliza modelos de Inteligência Artificial para extração de dados e geração de textos. Os cálculos de prazos são determinísticos e não dependem de IA.

5. Aceite

Ao aceitar estes termos, o usuário declara estar ciente das condições acima e se compromete a utilizar o sistema de forma ética e responsável.
